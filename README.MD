# 🌿 Plan Your Trip In Nature

- Responsive Design
- Nature Stay Listings
- Gallery
- Activities
- Contact Form
- Newsletter
- Smooth Animations

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

1. Clone the repository.
2. Open the project folder.
3. Run `index.html` using Live Server.
